# 425-design-project
bee425 design project millard/jacky



create a microprocessor-based function generator with the following specifications:

Outputs sine, square and triangle waves
Has a display to provide user feedback
Adjustable output, from 0 volts to maximum +/- 5V
10 Hz to 100 KHz frequency range
Built on a printed circuit board that you design
Uses a microcontroller as the control element 
Will run independently of a laptop computer
Battery operated or with an external power module (wall wart)

Optional features for :extra credit:
    Adjustable DC offset: 5 pts
    Mounted in an appropriate metal or plastic chassis: 5 pts
